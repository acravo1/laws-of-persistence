# Organizational Memory

## Introduction

Organizational Memory is one of the foundational concepts in knowledge management and organizational theory.

The concept describes how organizations store, preserve and retrieve knowledge accumulated over time.

It provides an important theoretical foundation for many of the ideas explored by the Laws of Persistence.

---

# Definition

Organizational Memory refers to the information, knowledge, experiences and practices that an organization retains and can access in the future.

These memories extend beyond individual employees.

Knowledge becomes embedded within organizational structures.


---

# Memory Repositories

Walsh and Ungson proposed that organizational memory can exist in multiple locations.

Examples include:

- individuals;
- organizational culture;
- processes;
- structures;
- repositories;
- external records.

Memory is therefore distributed rather than centralized.


---

# Purpose

The primary purpose of organizational memory is to allow organizations to use prior knowledge when making future decisions.

Organizational memory supports:

- learning;
- consistency;
- decision making;
- adaptation.

The ability to remember reduces the need to rediscover previously acquired knowledge.


---

# Memory and Continuity

Organizational memory contributes directly to continuity.

When knowledge survives personnel changes, organizations become more resilient.

The preservation of knowledge reduces dependence on individual memory.

Organizational memory therefore acts as a continuity mechanism.


---

# Relationship With The Laws of Persistence

The Laws of Persistence strongly align with the principles of organizational memory.

Both recognize that critical knowledge should survive individual turnover.

Both seek to reduce dependency on individuals.

Both treat knowledge preservation as a strategic objective.


---

# Key Difference

The primary difference concerns the ultimate objective.

Organizational Memory focuses on preserving knowledge.

The Laws of Persistence focus on preserving capability.

Knowledge is considered necessary.

Knowledge is not considered sufficient.


---

# Knowledge Versus Capability

An organization may successfully preserve knowledge while still losing operational capability.

Examples include:

- documented recovery procedures that have never been tested;
- preserved source code without maintainers;
- archived documentation without context;
- inventories without governance.

Memory survives.

Capability does not necessarily survive.


---

# Relationship With The Continuity Hypothesis

The Continuity Hypothesis extends the concept of organizational memory.

The relationship can be summarized as:

Memory
        ↓
Knowledge
        ↓
Capability
        ↓
Continuity

Memory supports continuity.

Continuity requires additional mechanisms.


---

# Relationship With The Hidden Knowledge Factory

The Hidden Knowledge Factory can be understood as memory that exists outside formal organizational memory structures.

Knowledge survives.

Visibility does not.

As hidden memory increases:

- governance decreases;
- dependency increases;
- continuity risk increases.


---

# Conclusion

Organizational Memory provides one of the strongest theoretical foundations for the Laws of Persistence.

The framework extends the idea by proposing that preserved memory should not be viewed as the final objective.

The ultimate objective is preserved capability.

Continuity emerges when capability survives time, change and disruption.
